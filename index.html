CSS Selector Playground

Explore different CSS selectors and see examples.

1. Element Selector

p { color: blue; }

All paragraph elements are selected.

2. ID Selector

#special { color: red; }

This paragraph has a unique ID.

3. Class Selector

.highlight { background: yellow; }

This uses a class selector.

4. Universal Selector

* { box-sizing: border-box; }

Selects every HTML element.

5. Group Selector

h2, p { font-family: Arial; }

Selects multiple element types.

6. Descendant Selector

div p { color: green; }

Selects paragraphs inside div elements.

7. Child Selector

div > p { color: purple; }

Selects direct child paragraphs.

8. Attribute Selector

input[type="text"]

9. Pseudo-class Selector

button:hover { background: green; }

10. Pseudo-element Selector

p::first-letter { color: red; }

This paragraph demonstrates a pseudo-element.

11. Adjacent Sibling Selector

h3 + p { color: orange; }

Heading

Paragraph immediately after heading.

12. General Sibling Selector

h3 ~ p { color: brown; }

Another heading

First sibling paragraph.

Second sibling paragraph.
